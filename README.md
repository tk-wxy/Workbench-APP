# Workbench App

[中文](#中文) · [English](#english)

## 中文

Workbench App 是一个面向 Windows 的全屏桌面工作台。通过全局快捷键呼出，用完即隐藏，让常用操作停留在桌面之上、而不打断当前工作。

- 启动台：固定并快速启动常用应用
- 中转站：暂存文本、图片与文件，方便继续拖放或粘贴
- 剪贴板历史：按文本、截图和文件分类浏览，支持页面搜索与关键词高亮
- 增强搜索：以 `Ctrl+K` 统一搜索应用、文件、中转站和剪贴板内容

### 使用

从 [Releases](../../releases) 下载最新的 Windows 安装包并安装。启动后按应用设置的全局快捷键即可呼出工作台；默认快捷键可在应用设置中调整。

Workbench App 目前仅支持 Windows，并以主显示器工作区为目标设计。

## English

Workbench App is a full-screen Windows desktop workspace. Open it with a global shortcut, finish what you need, and let it disappear without interrupting the desktop underneath.

- Launcher: pin and open frequently used apps
- Stage: hold text, images, and files for the next drag, drop, or paste
- Clipboard history: browse text, screenshots, and files with category filters and highlighted page search
- Enhanced search: use `Ctrl+K` to search apps, files, stage items, and clipboard content from one place

### Get started

Download and install the latest Windows package from [Releases](../../releases). Launch the app and use its configured global shortcut to open the workspace; the default shortcut can be changed in Settings.

Workbench App currently supports Windows and is designed for the primary display workspace.
