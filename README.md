# Workbench App

Windows 全屏"第二桌面"工具——热键呼出覆盖全屏的功能界面，用完优雅消失，原桌面不受影响。理念 ≈ "功能增强版的开始菜单"。

**功能**：应用启动器 · 文件中转站 · 剪贴板历史 · 全盘文件搜索

## 技术栈

Tauri 2.0（Rust 后端）+ React 18 + TypeScript + Vite + Tailwind CSS。目标包体 ~5MB、内存 ~30MB。

## 运行

```bash
npm install
npm run tauri dev    # 开发
npm run tauri build  # 打包
```

## 快捷键

| 操作 | 默认热键 |
|------|---------|
| 呼出/隐藏 | `Ctrl+Space`（长按 = 按住显示、松开关闭；短按 = 切换） |
| 增强搜索 | `Ctrl+K` |
| 关闭/返回 | `Esc` |

热键可在设置面板自定义（支持录制式输入）。点击界面外的其他应用会自动隐藏（light dismiss）。

## 核心功能

- **应用启动器**：扫描已安装应用，收藏托盘 + 拖拽排序 + 键盘导航（开始菜单风格）
- **文件中转站**：拖入暂存文件，拖出/取走到任意位置；支持多选、框选、批量操作、单条固定、可选持久化，图片文件显示缩略图
- **剪贴板历史**：自动记录文本 / 图片 / 文件三类历史，点击即粘贴回目标应用，容量可调，图片原图缓存自动管理
- **增强搜索**（`Ctrl+K`）：一个入口聚合搜索应用、中转文件、剪贴板历史与全盘文件
- **界面语言**：中 / 英文切换（含托盘菜单）

## 搜索引擎

- **内置引擎**：遍历常用目录建内存索引，子序列模糊匹配，µs 级查询，后台预建零等待
- **Everything**：可选切换 Everything 引擎，全盘毫秒级搜索。设置 → 搜索 → 选 Everything 即可
